# 小肥鱼网页演示版

双击 `index.html` 即可在浏览器中运行。刷新网页会从零重新开始，在第 5、30、50 秒收到三封预设邮件；第 1、3 封同步加入“提醒”页。点击桌面邮件图标展开窗口，首次打开会提示右键邮件试用功能；图标和标题栏可以拖动，窗口四边与四角可以调大小。

在“对话”页输入「删掉提醒页面中的所有内容」并发送，等待 5 秒后显示预设回复与后续指引。邮件右键菜单中的手动提醒会说明演示版暂不支持。页面不连接真实邮箱、DSH，也不保存个人数据。

这是无构建依赖的静态网页。部署 GitHub Pages 时，将本目录作为站点根目录，或把 `index.html` 与 `app.js` 放到仓库根目录。资源路径均为相对路径。
